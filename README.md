# NIM Account Management

# Description
**NIM Account Management** provides centralized administration of user accounts, permissions, and access controls within NIM. The application enables administrators to efficiently manage user accounts, perform account maintenance tasks, and control access to NIM applications and administrative functions.

Administrators can update user profiles, reset passwords, clear Multi-Factor Authentication (MFA) status, and enable or disable accounts as needed. The application also provides comprehensive group management capabilities, allowing administrators to control application access, assign permissions, and delegate administrative responsibilities through role-based access controls.

By centralizing user and group administration, NIM Account Management helps improve security, streamline operational processes, and ensure consistent access governance across the NIM platform.

# Prerequisites
- [Standard Item Library](https://github.com/Tools4ever-NIM/NIM-Framework-ItemLibrary)

# Installation
- Download app.json source file
- Within NIM
- 	Go to Apps
- 	Click Import
- 	Select app.json
-	Create each missing audit query
- 	Complete Import
- 	Under Apps, Uncheck "Exportable" if checked
